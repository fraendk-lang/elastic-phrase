# Phrase Soundfonts (MusyngKite)

Self-hosted GM instruments for Elastic Phrase melody preview.

```bash
npm run fetch:soundfonts
npm run check:soundfonts
```

Load order: local MusyngKite → CDN MusyngKite → FluidR3 → synth fallback.
